SAVEFILE_VERSION_MINPlaceholder to check against the SAVE_DATA_EMPTY and SAVE_DATA_OBSOLETE values. Any generated save data version will be zero or a positive integer, so it's only necessary to check against this value for anything negative (error states). Typically signifies an empty list, where the savefile is not loaded or the character is new. Will just trigger a regeneration. The save data is below the accepted minimum and should be reset. This is the lowest supported version, anything below this is completely obsolete and the entire savefile will be wiped.
SAVEFILE_VERSION_MAXThis is the current version, anything below this will attempt to update (if it's not obsolete) You do not need to raise this if you are adding new values that have sane defaults. Only raise this value when changing the meaning/format/name/layout of an existing value where you would want the updater procs below to run
